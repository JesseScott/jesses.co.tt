Git 3D



Git 3D (GitGraph 3D) is a visualizer that turns the history of a Git repository into a place you can walk through. Time runs along one axis, branches fan out into lanes either side, and each commit is a node you can click to see its details.

You point it at a repository on your own machine and it reads the history locally. Walk forwards and back along the commits with the arrow keys or WASD, hop between branch lanes, or switch to a free orbit camera to look at the whole thing from outside. Repositories you have imported are remembered, so you can come back to them and re-import to pick up new commits.

It is built with React Three Fiber on the front end and a small Express server that runs Git and hands the history over as JSON. It runs entirely on your own computer, and the source (MIT licensed) is on GitHub.
